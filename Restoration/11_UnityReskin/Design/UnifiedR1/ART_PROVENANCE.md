# 美术来源与制作

仅应用到 `11_UnityReskin` 副本。参考为用户确认的天空、云朵、玻璃面板、绿色按钮和蓝金 2000 筹码。

使用内置 **image_gen**，未调用付费 API 脚本。完整生成原图保留在 `GeneratedPanel.png`、`GeneratedMachine.png` 及 `../CoinR1/{Blank,Panels,Background}.png`。

提示词任务：

- 空白弹窗：天空蓝高光玻璃框、蓝色标题栏、浅蓝内容区、角落云朵，透明外背景；不绘制文字、按钮或奖励。
- 抽奖机：按主界面天空蓝风格制作高光玻璃机身、九宫格凹槽、侧拉杆、绿色顶灯，透明外背景；奖励图标由 Unity 独立显示。
- 筹码提现页 Blank：从用户参考图去除文字与金额，保留原布局、全部面板、选中/未选中按钮、灰色进度槽和提现按钮。
- 筹码提现页 Panels：继续去除紫色栏内的金币、六个金额按钮、勾选和底部按钮，补齐对应背景，保持外框位置和颜色。
- 筹码提现页 Background：移除全部 UI、返回按钮、分割线、面板和进度槽；恢复天空、云朵、草地、叶子与小花，保留 941×1672 竖屏构图，不添加文字或金币。

`prepare.cjs` 与 `../CoinR1/prepare.cjs` 只执行技术切图、透明蒙版和边缘清理。每张素材的尺寸、透明像素数、抗锯齿像素数和 SHA-256 见同目录 `materials.json`。

2000 筹码复用用户此前确认的 `Assets/Resources/RulesReskin/Chip2000.png`。绿色按钮复用已确认的 `CashReskin/Withdraw.png`。大图按弹窗启用/禁用时加载释放；没有新增第三方程序集。
