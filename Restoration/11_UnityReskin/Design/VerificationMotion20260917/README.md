# 提现验证动画调整

只调整副本 B 版的 Withdraw request 弹窗动画。

- 入场从 96% 轻微缩放并淡入到原尺寸，去掉过冲回弹；时长仍为 0.35 秒。
- 状态文字保持正常字号，从下方 8 个 UI 单位平滑移动并淡入；出现时点及 0.4 秒时长保持原值。
- 等待图标连续旋转，勾选图标平滑淡入。旧动画仍控制状态与完成事件，游戏规则不依赖新视觉效果。
- 关闭后还原文字位置、缩放和透明度，避免多次打开累积偏移。

验证结果见 `validation.json`：以固定 60 fps 分别运行修改前与修改后的完整实际提现验证，两次均为 6.6 秒，均且仅推进一次任务。检查了文字透明度单调、文字不缩放、外框不超出原尺寸、关闭后还原。

原生预制体和场景的文字、精灵引用、坐标、尺寸、存档命名及验证阶段时间均与上一个 Git 检查点相同；只有此弹窗与三个状态图标启用了平滑效果。其他弹窗维持原动画模式。

`before/` 与 `after/` 是本地测试采样帧（15 fps 采样，游戏本身按 60 fps 验证），用于排查，不作为完整视觉帧率演示。商业 SDK 仍为原来的模拟实现。
