# 高清硬币修复 — 2026-09-23

- 主界面提现图标原来从 AnNiu_TX 图集的 56 × 59 像素区域读取 2000 硬币，放大后模糊。现在同一个原生骨骼网格直接采样已有的 `RulesReskin/Chip2000` 高清原图（1254 × 1254），沿用原始未打包 UV。没有修改骨骼、网格顶点、三角形、裁剪、纸钞动画或绘制顺序。
- 渲染器支持一个可选高清附件，未配置的动画仍使用原图集。高清附件在首次绑定时通过 Resources 加载，材质随组件销毁释放；逐帧不创建材质或额外 UI 对象。
- 操作区 11 张硬币 PNG 的解码像素与用户提供的原图逐张核对，全部一致。改为 RGBA32 无损导入，保留 1254 × 1254 分辨率，清除平台压缩覆盖；未修改 PNG、Sprite GUID、PPU、边框、网格类型、碰撞或尺寸设置。无损纹理会比原来的有损 GPU 压缩占用更多显存。

验证：Unity 2022.3.62f3c1 独立副本以正常启动流程进入 Play Mode，通过一次性存档检查 11 种硬币的实际 TextureFormat 和尺寸。对比动画 0.3333、0.75、1.5 秒的同姿态 GPU 截图，确认高清纹理生效，23 个网格顶点位置逐个保持一致；检查朝向及前景纸钞遮挡。1080 × 1920 和 1080 × 2340 主界面检查通过。
