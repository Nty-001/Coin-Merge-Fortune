# 硬币提现金额区域边缘修复 — 2026-09-23

修复范围仅为 `Select amount` 的面板切片、按钮底板匹配及滚动裁切范围。

- `Amounts.png` 的内侧圆角延伸到标题下方，旧的顶部九宫格边界 150 像素穿过圆角。改为左/下/右/上 90/76/90/198 像素，保留完整内外圆角，继续以原生 Sliced Image 适配长屏。
- 原浅蓝按钮图为 412 × 155，绿色选中图为 421 × 166，后者包含右下方外伸的勾选标记。把两张图放在相同 Rect 中并各自 Preserve Aspect 会导致绿色矩形主体缩小、露出浅蓝边框。现在将绿色图的 411 × 153 主体窗口对齐浅蓝底板，勾选标记自然向右下延伸；绿色与浅蓝主体的非透明边缘重合。各状态文字沿用相同的页面坐标。
- 原列表两列总宽超出 viewport，导致左右按钮边缘被硬切。只扩展滚动列表的水平裁切范围，不裁切面板装饰。增加底部内容留白，让最后一排选中角标在滚动到底时完整露出。中间滚动时正常的上下裁切仍然保留。
- 原始 `GameWithdrawItem.refreshSelectBGSprite` 仅控制选中层显隐；原始节点中选中图相对未选中图同样向右下延伸。修复保留此叠加方式，未改 `RecoveredMainMenus`、提现门槛、金额配置、标准 Button 或事件绑定。

制作入口：`CoinMerge.Recovery.Editor.CoinAmountPanelAuthor.Run`。仅对当前 `RecoveredMain.prefab` 与 `RecoveredMain.unity` 的 56 个目标 RectTransform/Image 组件应用改变，排除 Unity 保存时自动修改的无关文本/其他组件。原 PNG 图片未编辑。

验证：Unity 2022.3.62f3c1，独立校验副本通过原始启动场景进入 Play Mode。使用真实绑定的 Button 切换 $800 / $5,000 / $500，使用 ScrollRect 的滚轮事件滚到底，检查主体重合、两侧角标不越界、文字基线不跳动、末排下方留白。1080 × 1920 与 1080 × 2340 实际渲染截图通过检查。最终复核使用当前工程精确应用后的场景/预制体及最新素材。未打包。
