- 图片由内置 `image_gen` 生成；[首轮提示词](prompts.json)、[规则图修订提示词](revision-prompt.json) 已保存。
- 这些是视觉审核稿，不是已经应用的运行截图。数字、语言、支付平台、按钮可用状态等继续由原逻辑驱动；法律正文使用项目已有文本，不从生成图识别回填。
- 本轮只审弹窗/卡片范围；审核图背景的细小生成差异不属于首页修改。替换时需以当前预制体和原游戏尺寸为准，重新实测不同长宽比，禁止整张效果图拉伸当界面。
